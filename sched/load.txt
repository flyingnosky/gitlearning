# Load of LAVD scheduler

## taskc related

### taskc->lat_cri
  (log2(wait_ft * wake_ft) + log2(p->scx.weight)) * (log2(wait_ft * wake_ft) + log2(p->scx.weight))
  taskc->wait_freq = LAVD_TIME_ONE_SEC / (now - taskc->last_quiescent_clk) * 1/8 + taskc->wait_freq * 7/8  (lavd_quiescent)
  taskc->wake_freq = LAVD_TIME_ONE_SEC / (now - taskc->last_runnable_clk) * 1/8 + taskc->wake_freq * 7/8  (lavd_runnable)
### taskc->perf_cri
  has_little_core ->  log2(wait_ft * wake_ft) + log2((taskc->run_freq * taskc->avg_runtime) >> LAVD_SHIFT * p->scx.weight)
  taskc->run_freq = LAVD_TIME_ONE_SEC / (now - taskc->last_quiescent_clk + taskc->avg_runtime) * 1/8 + taskc->run_freq * 7/8  (lavd_runnable)
### taskc->acc_runtime
  taskc->acc_runtime += now - (taskc->last_measured_clk + cpuc->online_clk - cpuc->offline_clk)  (stopping / tick)
### taskc->avg_runtime
  taskc->avg_runtime = task->avg_runtime * 0.75 + taskc->acc_runtime * 0.25

## cpuc related
### cpuc->idle_total
    记录在当前周期内CPU的idle总时间
### cpuc->cur_util
    当前CPU的cur_util = (c->duration - cpuc->idle_total) / c->duration
### cpuc->avg_util
    cpuc->avg_util = cpuc->avg_util * 7/8 + cpuc->cur_util * 1/8，它用于scaling frequency
### cpuc->nr_pinned_task
    记录当前CPU上等待执行（enqueue +1）的pinned task数量，在pinned task running时-1；
    若sys_stat.nr_queued_task <= sys_stat.nr_active，can_boost_slice()返回true
### cpuc->tot_svc_time
    svc_time = runtime / p->scx.weight：运行时间
    sc_time = scale_cap_freq(runtime, cpu_id): 经过freq/cap归一化后的运行时间
    记录当前CPU上一个周期内的svc_time
### cpuc->tot_sc_time
    记录当前CPU上一个周期内的sc_time
###　cpuc->cur_sc_util
    cpuc->cur_sc_util = cpuc->tot_sc_time / c->duration，当前CPU sc_time的利用率
### cpuc->avg_sc_util
    cpuc->avg_sc_util = 7/8 * cpuc->avg_sc_util + 1/8 * cpuc->cur_sc_util
### cpuc->nr_perf_cri
    判断task是否为perf_cri，是通过函数is_perf_cri()，即taskc->perf_cri是否超过sys_stat.thr_perf_cri
    cpuc->nr_perf_cri表示运行在CPU上的perf_cri task的数量
### cpuc->nr_lat_cri
    判断task是否为lat_cri，是通过函数is_lat_cri()，即taskc->lat_cri是否超过sys_stat.avg_lat_cri
    cpuc->nr_perf_cri表示运行在CPU上的lat_cri task数量
### cpuc->nr_x_migration
    task运行在不同的cpdom上的次数
### cpuc->sum_lat_cri
    记录运行在CPU上task的lat_cri的总和;
### cpuc->nr_sched
    记录运行在CPU上task总数
### cpuc->nr_preempt
    记录在CPU上发生抢占的次数
### cpuc->max_lat_cri

## sys_stat
### sys_stat.thr_perf_cri
    用于判断task是否为perf cri，若task的perf_cri大于thr_perf_cri，则为perf cri的task;
    它主要使用在：
    - 在pick_idle_cpu()时选核考虑perf cri task与大核匹配
    - 在running时统计cpuc->nr_perf_cri数量

    函数update_thr_perf_cri()在每个周期到来时Update sys_stat.thr_perf_cri，它与sys_stat.max_perf_cri/min_perf_cri/avg_perf_cri来计算。
### sys_stat.nr_queued_task
    当前系统中排队的task数量，
    她主要使用在：
    - migration计算负载时
    - can_boost_slice()计算是否boost slice: 若nr_queued_task < nr_active时，需要boost；否则不需要boost
### sys_stat.slice
    若nr_queued_task > 0, slice = 8ms * sys_stat.nr_active / nr_q
    否则 slice = slice_max_ns = 5ms

    slice_max_us:5000
    slice_max_us: 500

    函数calc_time_slice计算task的slice:
    - 同时满足以下三个条件，可以boost slice
      - !no_slice_boost：没有定义no_slice_boost
      - !cpuc->nr_pinned_tasks: 没有pinned task在等待
      - taskc->avg_runtime >= sys_stat.slice：运行时间大于sys_stat.slice
    若can_boost_slice()即nr_queued_task < nr_active时，slice = clamp (taskc->avg_runtime + LAVD_SLICE_BOOST_BONUS)
    否则系统为high load，仅仅对lat_cri > avg_lat_cri的task进行boost slice，slice = sys_stat.slice + sys_stat.slice * taskc->lat_cri / (sys_stat.avg_lat_cri + 1)
    不进行boost slice时，slice = sys_stat.slice

    函数shrink_boosted_slice_remote(cpuc, now)将之前设置为LAVD_FLAG_SLICE_BOOST的task的slice恢复：
    - 若达到sys_stat.slice时间，执行scx_bpf_kick_cpu(SCX_KICK_PREEMPT)抢占
    - 若没有达到sys_stat.slice时，在sys_stat.slice - dur后放弃CPU
    函数shrink_boosted_slice_at_tick()在tick到来时调整boost slice,作用与shrink_boosted_slice_remote类似
### sys_stat.avg_svc_time
    sys_stat.avg_svc_time = c->tot_svc_time / c->nr_sched
    它在计算greedy时用，calc_greedy_penalty()，用于计算calc_when_to_run()。
### sys_stat.avg_sc_util
    sys_stat.avg_sc_util = calc_asym_avg(sys_stat.avg_sc_util, c->curr_sc_util) 
    它用于power mode中core compaction中计算nr_active_cpu，calc_required_capacity()。
### sys_stat.avg_util
    c->cur_util = (c->duration_total - c->idle_total) / c->duration_total
    sys_stat.avg_util = calc_asym_avg(sys_stat.avg_util, c->cur_util)
    目前没有看到在其他地方使用
### sys_stat.thr_lat_cri
    sys_stat.thr_lat_cri = sys_stat.max_lat_cri - ((sys_stat.max_lat_cri - sys_stat.min_lat_cri)>>preempt_shift)
    它用于preempt，若task的lat_cri大于thr_lat_cri，可以preempt其他task
### sys_stat.avg_lat_cri
    c.avg_lat_cri = c->sum_lat_cri / c->nr_sched
    sys_stat.avg_lat_cri = calc_avg32(sys_stat.avg_lat_cri, c->avg_lat_cri)
    它用于判断当前task是否为lat_cri （is_lat_cri（）），若task的lat_cri大于sys_stat.avg_lat_cri，它为lat_cri;
    另外在pipeline中需要使用它来过滤部分task
